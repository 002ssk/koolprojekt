# Õpirahu — Smart Study Planner

Mobiilisõbralik õppeplaneerija ülesannete, tähtaegade, õppeaja ja fookussessioonide haldamiseks. Rakendus kasutab ainult HTML-i, CSS-i ja puhast JavaScripti; kogu info salvestatakse selle brauseri `localStorage`-isse.

## Käivitamine

Ava `index.html` tänapäevases veebibrauseris. Serverit ega andmebaasi pole vaja.

## Funktsioonid

- Lisa kodutöid, kontrolltöid ja õppimisülesandeid koos aine, tähtaja, prioriteedi ning ajahinnanguga.
- Vaata automaatselt tähtaja ja prioriteedi järgi järjestatud kuni kolme tunni päevaplaani.
- Märgi ülesandeid tehtuks, filtreeri või otsi neid ning jälgi päeva- ja nädalapõhist edenemist.
- Kasuta ülesandega seostatavat 25/5-minutilist Pomodoro taimerit.
- Ülesanded, fookussessioonid ja taimeri olek püsivad lehe värskendamisel.
